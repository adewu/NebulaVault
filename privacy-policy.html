NebulaVault Privacy Policy

Last updated: June 18, 2026

NebulaVault is a local privacy vault app for Android. This policy explains how the current app handles vault media, access passwords, security questions, permissions, advertising, and data deletion.

Data stored on this device

Vault photos, videos, thumbnails, encrypted media indexes, password verification data, security questions, security answer verification data, and wrapped encryption keys are stored locally in the app's private storage on the device. NebulaVault does not upload vault media, passwords, recovery answers, or encryption keys to a NebulaVault server.

Encryption and recovery

Vault media is encrypted locally before it is persisted in app-private storage. The access password and recovery answer are used to protect local key material. The app cannot recover the original vault if both the access password and security answer are lost; the user can only clear local vault data and create a new vault.

Camera, microphone, and media access

Camera permission is requested only when the user starts photo or video capture. Microphone permission is requested for video recording in the current app flow. Android Photo Picker is used for import so the app does not request full library access for importing. Export writes media to the system gallery only after the user confirms export.

Advertising

The Vault Home screen may show a Google AdMob banner. AdMob can contact Google services and may process advertising data according to Google's policies. NebulaVault does not send vault media, passwords, security answers, or raw file contents to AdMob.

Learn more about Google's advertising and privacy practices at https://policies.google.com/technologies/ads.

No cloud sync or analytics SDK

The current app does not provide cloud sync for vault contents and does not include a third-party analytics SDK. Google Play and Google AdMob may provide aggregate install, crash, and advertising reporting through their services.

Data deletion

Deleting a vault item removes its encrypted file, encrypted thumbnail, and media index entry. Clearing the private space removes vault media and local key material. Uninstalling the app or clearing app data removes local app data and may make vault contents unrecoverable.

Contact

For privacy questions, contact the developer through the Google Play listing for NebulaVault.
